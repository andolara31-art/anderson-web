# ANDERSON.AL — Portafolio de Anderson Agüero Lara

Portafolio personal construido con React, TypeScript, Tailwind CSS y Motion, alineado con el sistema visual de **NUVRO ENGINEER**.

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación y compilación

```bash
npm run lint
npm run build
```

## Despliegue en Vercel

El repositorio incluye `vercel.json` configurado para Vite (`npm install`, `npm run build`, carpeta `dist` y reescritura SPA hacia `/index.html`). No requiere variables de entorno secretas en el cliente.
